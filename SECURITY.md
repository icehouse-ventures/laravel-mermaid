# Security Policy

## Supported versions

Laravel 12 and 13, Mermaid 11, and PHP 8.2 through 8.5 receive security support in this major release.

The default Mermaid `securityLevel` is `strict`. Applications that relax it are responsible for ensuring all diagram content and HTML labels are trusted.

## Reporting a vulnerability

Please report vulnerabilities privately to tech@icehouseventures.co.nz rather than opening a public issue.
